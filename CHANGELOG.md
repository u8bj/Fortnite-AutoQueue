# Changelog

## 0.2.0-preview

- Added an open-source Electron interface launched with `npm start`.
- Added a violet/black Fortnite theme, animated key screen and engine loading transition.
- Added the local key `u8bj`, quiet typing/click/login sounds and a persistent mute switch.
- Added live dashboard, recognition results, settings and a handoff to the original calibration application.
- Connected the interface to the existing Python runtime with restricted IPC and JSON-lines messages.
- Preserved the state machine, focus/input guards, F8 stop, P ready-up and one-time Space jump behavior.
- Kept all 12 German crops and their preset. New captures are only needed when recognition fails on a user's setup.
- Updated setup, contributor and release documentation. No standalone EXE or installer is included.

## 0.1.0

- Published the Python/Tkinter source preview with German recognition templates.
- Restored the repository folder structure and added the source download.
